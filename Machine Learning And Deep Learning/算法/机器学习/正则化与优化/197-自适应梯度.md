## 适用场景
- 线性模型与因子分解机中的超稀疏输入训练。
- 词袋特征、推荐特征哈希等高维稀疏问题。
- 在线增量更新且需要低维护优化器配置的场景。

### 作用与产生背景
- AdaGrad 的核心作用是为每个参数维度分配不同的学习率，让高频特征自动降步长、低频特征保持较大的更新幅度。
- 它出现的直接背景是稀疏高维特征越来越常见，统一学习率往往会让常见特征更新过猛、罕见特征学不到东西。
- 因此 AdaGrad 更像是“按坐标自适应”的优化器，它优先解决的是特征频次差异，而不是复杂非凸目标下的最终最优收敛。

## 模型实现原理
AdaGrad按参数维度累计平方梯度
$$
G_t=\sum_{\tau=1}^{t} g_\tau\odot g_\tau,
$$
更新规则
$$
\theta_{t+1}=\theta_t-\eta\frac{g_t}{\sqrt{G_t}+\epsilon},
$$
按维度写为
$$
\theta_{t+1,i}=\theta_{t,i}-\frac{\eta}{\sqrt{\sum_{\tau=1}^t g_{\tau,i}^2}+\epsilon}g_{t,i}.
$$
因此高频更新维度步长快速减小，低频维度保持较大步长。

在凸优化下可得次线性遗憾界（简化形式）
$$
R_T\le \frac{\|\theta^*\|_2^2}{2\eta}\sum_i\sqrt{G_{T,i}}+\eta\sum_i\sqrt{G_{T,i}},
$$
显示其对坐标尺度自适应性。

## 主要优点
- 每维自适应步长天然适配特征频次差异。
- 对稀疏梯度任务收敛快，超参数需求少。
- 具备清晰在线学习理论背景。

## 主要缺点
- $G_t$单调累积导致有效学习率趋近0。
- 深度非凸任务后期易停滞在次优区域。
- 需额外存储与参数同维度的累积状态。

## 针对缺点的解决办法
- 用RMSprop/Adam引入指数衰减二阶矩避免无限累积。
- 训练后期重置累积器或切换优化器做精修。
- 配合学习率预热和梯度裁剪降低早期数值震荡。

## 常用参数
- `lr(\eta)`：初始学习率。
- `eps`：分母稳定项。
- `weight_decay`：正则化。
- `initial_accumulator_value`：初始$G_0$缓解过快衰减。

## 选型建议
- 稀疏线性/浅层模型可直接用AdaGrad作为首选。
- 深度网络长期训练建议优先RMSprop/Adam系列。

### D2L 迁移提示
- 在词袋、CTR、哈希特征这类高维稀疏问题上，可以优先沿用 D2L 的 AdaGrad 实现做 baseline，再视学习率过快衰减情况切到 RMSProp/Adam。
- 若有效学习率很早就接近零，优先检查是否需要 `initial_accumulator_value` 或直接改用指数遗忘二阶矩优化器。

## 模型解释方法
- 可视化$G_{t,i}$与有效学习率$\eta_i^{eff}$的演化。
- 对高频/低频特征分组比较收敛速率差异。
- 检查学习率衰减拐点与验证性能停滞是否同步。
## Python代码实现
下面给出一个教学版 AdaGrad 实现，用累计平方梯度为每个参数维度调整步长。

```python
import torch


class AdaGradLike:
    def __init__(self, params, lr=1e-2, eps=1e-10, weight_decay=0.0):
        self.params = list(params)
        self.lr = lr
        self.eps = eps
        self.weight_decay = weight_decay
        self.accumulators = [torch.zeros_like(p) for p in self.params]

    @torch.no_grad()
    def step(self):
        for p, acc in zip(self.params, self.accumulators):
            if p.grad is None:
                continue
            g = p.grad
            if self.weight_decay:
                g = g + self.weight_decay * p
            acc.addcmul_(g, g, value=1.0)
            p.addcdiv_(g, acc.sqrt().add(self.eps), value=-self.lr)

    def zero_grad(self):
        for p in self.params:
            if p.grad is not None:
                p.grad.zero_()
```
## 使用示例
最小示例：在稀疏输入特征上训练一个线性层，观察 AdaGrad 的稳定收敛。

```python
import torch
from torch import nn

x = torch.randint(0, 2, (256, 20)).float()
y = (x[:, :3].sum(dim=1, keepdim=True) > 1).float()
model = nn.Linear(20, 1)
loss_fn = nn.BCEWithLogitsLoss()
optimizer = AdaGradLike(model.parameters(), lr=0.2)

for _ in range(150):
    logits = model(x)
    loss = loss_fn(logits, y)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

print("final loss:", float(loss))
```
