## 适用场景
- 参数量大于样本量、验证集明显过拟合的神经网络。
- NLP与推荐中embedding后全连接层正则化。
- 需快速构建鲁棒基线的通用深度学习任务。

### 作用与产生背景
- Dropout 的核心作用是抑制神经元之间的共适应，让模型在训练阶段就学会“部分特征缺失时也能工作”。
- 它出现的直接背景是深层网络参数量快速增大后，训练集精度很高但验证集明显掉队，单靠早停和 L2 正则往往不够稳。
- 和传统正则不同，Dropout 不是直接约束权重大小，而是通过随机屏蔽激活逼近“多个子网络集成”的效果。

## 模型实现原理
对某层激活$h\in\mathbb{R}^d$采样掩码
$$
m_i\sim \mathrm{Bernoulli}(1-p),\quad \tilde{h}=m\odot h.
$$
inverted dropout训练时使用
$$
\tilde{h}=\frac{m}{1-p}\odot h,
$$
从而
$$
\mathbb{E}[\tilde{h}_i]=\mathbb{E}\left[\frac{m_i}{1-p}h_i\right]=h_i,
$$
测试时无需再缩放。

线性层$y=w^T\tilde{h}$的方差为
$$
\mathrm{Var}(y)=\sum_i w_i^2 h_i^2\frac{p}{1-p},
$$
可视为向激活注入与幅度相关的噪声，抑制神经元共适应。

从模型集成角度，Dropout近似对$2^d$个子网络做参数共享平均。

- D2L 默认采用 inverted dropout，使训练阶段激活的期望保持不变，因此推理阶段无需再次缩放输出。
- 教程同时给出从零实现和框架 API 实现，适合直接核对 `p` 的定义、掩码采样方式以及层放置位置。
- 若与 BatchNorm 同用，应先固定无 Dropout 基线，再逐层增加 `p`，避免把归一化带来的波动误判为 Dropout 收益。

## 主要优点
- 有效降低训练-验证性能差距，泛化提升明显。
- 不增加可学习参数，改造成本低。
- 对输入扰动和局部缺失具有一定鲁棒性。

## 主要缺点
- 随机屏蔽引入梯度噪声，收敛速度下降。
- 过大$p$会导致表示能力不足并出现欠拟合。

## 针对缺点的解决办法
- 前层用小drop率、后层用较大drop率，分层调节噪声强度。
- 结合余弦退火/预热学习率，缓解收敛变慢。
- 与BatchNorm同用时通常将Dropout放在激活后且靠近分类头。

## 常用参数
- `p`：丢弃概率（常见0.1~0.5）。
- `dropout_position`：层前/层后与残差分支位置。
- `schedule`：固定或随epoch变化的drop率。
- `mc_dropout`：推理时是否保留dropout用于不确定性。

## 选型建议
- 当模型容量明显过大、数据中等偏小时优先使用Dropout。
- 对大规模预训练模型微调，先小$p$试验再决定是否保留。

### D2L 迁移提示
- 如果问题本质是模型容量过大而非数据泄漏，优先按 D2L 的做法在全连接层或预测头上尝试小到中等 `p`，再决定是否向前层扩展。
- 如果加入 Dropout 后训练集和验证集同时变差，应先降低 `p` 或缩小模型，而不是继续叠加更多正则手段。

## 模型解释方法
- 对比train/eval激活分布，确认噪声注入强度是否合理。
- 监控不同$p$下的校准误差(ECE)与泛化间隙。
- 统计神经元失活频率，避免关键通道长期被屏蔽。
## Python代码实现
下面给出一个与 D2L 讲解一致的简化 PyTorch 实现，既保留手写 Dropout 层，也展示它如何嵌入 MLP。

```python
import torch
from torch import nn


def dropout_layer(x: torch.Tensor, p: float, training: bool) -> torch.Tensor:
    if not training or p == 0.0:
        return x
    if p >= 1.0:
        return torch.zeros_like(x)
    mask = (torch.rand_like(x) > p).float()
    return mask * x / (1.0 - p)


class MLPWithDropout(nn.Module):
    def __init__(self, in_features: int, hidden: int, out_features: int, p: float = 0.5):
        super().__init__()
        self.fc1 = nn.Linear(in_features, hidden)
        self.act = nn.ReLU()
        self.fc2 = nn.Linear(hidden, out_features)
        self.p = p

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = self.fc1(x)
        x = self.act(x)
        x = dropout_layer(x, p=self.p, training=self.training)
        return self.fc2(x)
```
## 使用示例
最小示例：在训练态与推理态分别前向一次，观察 Dropout 是否只在训练时生效。

```python
import torch

model = MLPWithDropout(in_features=8, hidden=32, out_features=2, p=0.3)
batch = torch.randn(4, 8)

model.train()
train_logits = model(batch)

model.eval()
eval_logits = model(batch)

print("train shape:", train_logits.shape)
print("eval shape:", eval_logits.shape)
print("same outputs:", torch.allclose(train_logits, eval_logits))
```
