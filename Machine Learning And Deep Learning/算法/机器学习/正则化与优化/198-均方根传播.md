## 适用场景
- 长序列建模中梯度尺度波动明显的训练。
- 强非平稳目标（强化学习值函数、在线更新网络）。
- 需要比AdaGrad更持久学习率的优化场景。

### 作用与产生背景
- RMSProp 的核心作用是保留 AdaGrad 的按维度自适应思想，但避免学习率因为历史梯度无界累积而过早衰减到几乎无法更新。
- 它出现的背景正是 AdaGrad 在长训练、非平稳目标和深度网络上经常“前期很快、后期停住”的问题。
- 因此 RMSProp 可以理解为“带遗忘机制的 AdaGrad”，重点在于让优化器更关注近期梯度统计而不是全部历史。

## 模型实现原理
RMSprop将AdaGrad累积平方梯度改为指数滑动平均：
$$
s_t=\rho s_{t-1}+(1-\rho)g_t^2,
$$
参数更新
$$
\theta_{t+1}=\theta_t-\eta\frac{g_t}{\sqrt{s_t}+\epsilon}.
$$
若加入动量
$$
v_t=\mu v_{t-1}-\eta\frac{g_t}{\sqrt{s_t}+\epsilon},\quad
\theta_{t+1}=\theta_t+v_t.
$$
与AdaGrad比较，RMSprop等价于用几何窗近似历史二阶矩：
$$
s_t=(1-\rho)\sum_{k=0}^{t-1}\rho^k g_{t-k}^2,
$$
旧梯度影响按$\rho^k$衰减，不会无限累积，从而避免学习率迅速归零。

## 主要优点
- 相比AdaGrad更适合长程训练，步长衰减更平缓。
- 对梯度尺度变化自适应，RNN中常更稳定。
- 实现简单，计算与内存成本适中。

## 主要缺点
- $\rho$过大响应迟缓，过小则噪声敏感。
- 极端非凸面可能出现局部振荡。
- 缺少像Adam那样广泛统一的偏差修正框架。

## 针对缺点的解决办法
- 常用$\rho\in[0.9,0.99]$，并联合学习率搜索。
- 搭配梯度裁剪与学习率退火减轻后期震荡。
- 需要更稳健泛化时可切换AdamW或SGD微调。

## 常用参数
- `lr(\eta)`：基础学习率。
- `alpha(\rho)`：平方梯度滑动系数。
- `eps`：分母稳定项。
- `momentum`：可选一阶动量。

## 选型建议
- 序列模型若Adam不稳定，可尝试RMSprop+裁剪。
- 大规模视觉任务通常优先AdamW或SGD，RMSprop作为备选。

### D2L 迁移提示
- 当 AdaGrad 衰减过快但 Adam 又显得过于激进时，RMSProp 往往是更稳的中间方案。
- 如果验证曲线振荡明显，优先调平滑系数和学习率，再决定是否升级到 Adam 或加入动量变体。

## 模型解释方法
- 监控$s_t$均值与方差，判断二阶矩是否过度平滑。
- 分析有效学习率$\eta/(\sqrt{s_t}+\epsilon)$在各层分布。
- 比较不同$\rho$下loss震荡幅度与收敛速度。
## Python代码实现
下面给出一个教学版 RMSProp 实现，用指数滑动平均缓解 AdaGrad 学习率衰减过快的问题。

```python
import torch


class RMSPropLike:
    def __init__(self, params, lr=1e-3, alpha=0.99, eps=1e-8, weight_decay=0.0):
        self.params = list(params)
        self.lr = lr
        self.alpha = alpha
        self.eps = eps
        self.weight_decay = weight_decay
        self.avg_sq = [torch.zeros_like(p) for p in self.params]

    @torch.no_grad()
    def step(self):
        for p, avg in zip(self.params, self.avg_sq):
            if p.grad is None:
                continue
            g = p.grad
            if self.weight_decay:
                g = g + self.weight_decay * p
            avg.mul_(self.alpha).addcmul_(g, g, value=1 - self.alpha)
            p.addcdiv_(g, avg.sqrt().add(self.eps), value=-self.lr)

    def zero_grad(self):
        for p in self.params:
            if p.grad is not None:
                p.grad.zero_()
```
## 使用示例
最小示例：在带噪声的回归数据上训练一个线性层，观察 RMSProp 的收敛效果。

```python
import torch
from torch import nn

x = torch.randn(512, 10)
y = x[:, :1] * 2.5 - 0.8 + 0.1 * torch.randn(512, 1)
model = nn.Linear(10, 1)
loss_fn = nn.MSELoss()
optimizer = RMSPropLike(model.parameters(), lr=1e-2, alpha=0.95)

for _ in range(200):
    pred = model(x)
    loss = loss_fn(pred, y)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

print("final loss:", float(loss))
```
