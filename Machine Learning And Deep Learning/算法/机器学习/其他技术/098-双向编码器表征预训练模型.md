## 适用场景
- 句子/文档分类（情感、主题、意图）。
- 命名实体识别、关键词抽取等序列标注。
- 抽取式问答（给定上下文定位答案span）。
- 语义匹配与检索重排序（sentence pair任务）。

### 作用与产生背景
- BERT 的核心作用，是先用海量无标注文本学到可迁移的双向上下文表示，再把这套表示迁移到分类、匹配、抽取等下游任务上。
- 它出现的背景是：传统词向量只能给出静态词表示，而很多 NLP 任务真正需要的是“同一个词在不同语境里的不同含义”。
- 相比单向语言模型，BERT 通过掩码语言模型在训练时同时看左右文，目标就是让编码器更适合判别式自然语言理解任务。

## 模型实现原理
输入序列嵌入为 token、position、segment 三者相加：
$$
E_i=E^{tok}_{x_i}+E^{pos}_i+E^{seg}_{s_i}.
$$
经 $L$ 层Transformer Encoder得到上下文表示 $H^{(L)}$。

单头自注意力：
$$
\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V.
$$
多头拼接后线性映射得到层输出。

### 预训练目标
1) 掩码语言模型（MLM）
$$
L_{MLM}=-\sum_{m\in M}\log P(x_m\mid x_{\backslash M}).
$$
2) 下一句预测（NSP）
$$
L_{NSP}=-\log P(y_{nsp}\mid h_{[CLS]}).
$$
总损失
$$
L=L_{MLM}+L_{NSP}.
$$

### 微调
在任务头 $g_\phi(\cdot)$ 上联合优化
$$
\min_{\theta,\phi} \frac1N\sum_{i=1}^N \ell\big(g_\phi(h_{[CLS]}^{(i)}),y_i\big).
$$

## 主要优点
- **双向语义建模**：对上下文依赖敏感，NLP判别任务表现强。
- **迁移学习有效**：少量标注即可达到高质量结果。
- **生态成熟**：预训练权重与微调工具链丰富。

## 主要缺点
- **计算开销大**：自注意力复杂度约 $O(n^2)$。
- **长文本受限**：`max_seq_len` 受显存限制。
- **概率过置信风险**：需要额外校准提升置信度可靠性。

## 针对缺点的解决办法
- 采用蒸馏模型（TinyBERT/DistilBERT）降低延迟。
- 参数高效微调（LoRA/Adapter）减少显存与训练时间。
- 长文任务用滑窗分块、层次编码或长序列Transformer替代。
- 通过温度缩放与阈值策略改进预测置信校准。

## 常用参数
- `num_layers`、`hidden_size`、`num_heads`：模型容量核心参数。
- `max_seq_len`：输入长度上限。
- `learning_rate`、`warmup_ratio`：微调稳定性关键。
- `batch_size`、`weight_decay`：泛化与收敛控制。

## 选型建议
- 判别式NLP任务优先BERT/RoBERTa等编码器模型。
- 资源受限设备部署优先蒸馏或量化版本。
- 需要长文本跨段推理时，优先Longformer/DeBERTa等改进架构。

### D2L 迁移提示
- 文本分类、序列标注、抽取式问答这类判别任务，仍然适合先从 BERT 或其改进版本起步。
- 如果任务是自由生成、长文续写或工具调用，优先考虑解码器或编码器-解码器架构，而不是硬把 BERT 改成生成模型。

## 模型解释方法
- 可视化关键层注意力矩阵，分析词间依赖。
- 用Integrated Gradients衡量token对预测类别贡献。
- 对MLM任务查看被掩码词Top-k候选，验证语义理解质量。
## Python代码实现
下面给出一个教学版 `MiniBERTClassifier`，用 PyTorch 原生模块把 token/position/segment embedding、编码器和分类头串起来。

```python
import torch
from torch import nn


class MiniBERTClassifier(nn.Module):
    def __init__(
        self,
        vocab_size: int,
        hidden_size: int = 128,
        num_layers: int = 2,
        num_heads: int = 4,
        max_len: int = 128,
        num_classes: int = 2,
    ):
        super().__init__()
        self.token_embedding = nn.Embedding(vocab_size, hidden_size)
        self.position_embedding = nn.Embedding(max_len, hidden_size)
        self.segment_embedding = nn.Embedding(2, hidden_size)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=hidden_size,
            nhead=num_heads,
            dim_feedforward=hidden_size * 4,
            dropout=0.1,
            batch_first=True,
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)
        self.classifier = nn.Linear(hidden_size, num_classes)

    def forward(
        self,
        token_ids: torch.Tensor,
        segment_ids: torch.Tensor,
        attention_mask: torch.Tensor | None = None,
    ) -> torch.Tensor:
        batch_size, seq_len = token_ids.shape
        positions = torch.arange(seq_len, device=token_ids.device).unsqueeze(0).expand(batch_size, -1)
        x = (
            self.token_embedding(token_ids)
            + self.position_embedding(positions)
            + self.segment_embedding(segment_ids)
        )
        padding_mask = None
        if attention_mask is not None:
            padding_mask = attention_mask == 0
        encoded = self.encoder(x, src_key_padding_mask=padding_mask)
        cls_repr = encoded[:, 0]
        return self.classifier(cls_repr)
```
## 使用示例
最小示例：构造一批伪 token 序列，执行一次 BERT 风格分类前向和损失计算。

```python
import torch
from torch import nn

model = MiniBERTClassifier(vocab_size=30522, hidden_size=64, num_layers=2, num_heads=4, max_len=32)
token_ids = torch.randint(0, 30522, (4, 16))
segment_ids = torch.zeros_like(token_ids)
attention_mask = torch.ones_like(token_ids)
labels = torch.tensor([0, 1, 1, 0])

logits = model(token_ids, segment_ids, attention_mask)
loss = nn.CrossEntropyLoss()(logits, labels)

print("logits shape:", logits.shape)
print("loss:", float(loss))
```
